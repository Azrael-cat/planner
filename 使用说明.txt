桌面任务小助手 1.0

安装与启动
双击“安装小助手.cmd”。程序安装到当前用户的 LocalAppData\DeskTaskAssistant\app，
创建桌面和开始菜单快捷方式，并启用登录 Windows 后自启动。无需管理员权限。
也可直接双击 DeskTaskAssistant.exe 试用。程序需要 Windows 自带的 .NET Framework 4.x。

第一次使用
1. 点击卡片上的“任务与统计”，在“工作设置与备份”设置每天工作时间、总结时间和每周配额。
2. 在“总任务”添加任务内容、总数量、开始日期、截止日期和复习间隔。
3. 卡片按总任务合并显示“今日已完成 / 今日计划”。点击任务或“更新完成数量”，输入累计已完成份数；也可加 1 或全部完成。减少数量可撤销。复习与原任务分组显示，附加任务按内容、日期和来源合并。
4. 每天打开“每日总结”，记录进展，可同时添加明天或未来某天的附加任务。
5. “全部安排”每个总任务只显示一行，汇总总进度、今日数量和复习数量。双击后按日期查看汇总明细，并可调整或删除未完成的复习、附加任务。
6. “进度与效率”给每个总任务单独显示进度、今日完成情况、效率、复习进度和近 14 天图表。向下滚动查看全部任务和总结，悬停图表可查看当天确切完成量。

分配规则
每日配额按权重自动归一化。例如周一至周五分别为 20，周末为 0，即每周工作 5 天。
80/20 表示两天分配 80% 和 20%；不要求输入数值相加为 100。
每项总任务独立分摊至开始日期与截止日期之间的可工作日（包括截止日）。
整数份数无法完全符合百分比时，按累计比例取整。
每天 00:00 自动切换今日清单（程序运行且电脑未休眠时）。
今日未完成数量全部累加到次日原定数量，保留原计划日期，不摊薄到未来日期。
卡片显示“今日新增”和“往日结转”；休息日不新增计划任务，但仍显示积压。
修改总任务或工作设置时，只重排未来未完成份数，今日和积压份数保留。
已完成份数不会重新安排。当天完成一份不会立即重排剩余任务。
截止日前没有可工作日时，安排在截止日；已过截止日仍未完成的份数全部显示在今天，保留原定日期。
工作起止时间用于展示与效率估算，不限制提前或晚间完成任务；暂不支持跨午夜班次。
总任务创建后数量固定，新增数量请另建任务；名称、日期、复习间隔可编辑。

复习、附加任务与总结
复习间隔 7 天：某份任务实际完成日 + 7 个自然日出现一次复习，复习不会继续无限生成。
复习设置只影响此后完成的份数；已有复习日期可在“全部安排”调整。
未完成的复习和附加任务在到期后持续显示，直至完成或手动删除。
减少完成数量会删除对应的未完成复习；复习已完成的原任务份数不能撤销。数量调整会先检查可撤销份数，避免部分撤销。
未来附加任务显示来源总结日期，可在“全部安排”调整日期或删除。
每天总结可重复编辑；每次保存填写的附加任务都会新增，请勿重复提交相同任务。
到总结时间会显示系统气泡提示并展开卡片，每天提醒一次。系统通知设置可能抑制气泡。
电脑关机、休眠或退出期间无法实时更新；恢复或重新启动后立即补更新跨天任务与总结提醒。

统计说明
总进度只统计总任务，不把复习和附加任务重复计算进去，包含归档任务。
今日完成率 = 今天已完成份数 / 卡片今日全部份数。
效率 = 今日完成份数 / 设置的每日工作小时数，是估算值，不是实际工作计时。
不同任务每份的难度可能不同，图表不可视作严格生产力评分。
归档保留历史，但该任务的待办及复习不再显示在卡片；恢复后重新分配。

窗口和数据
拖动卡片深色标题区或窗口标题栏移动位置；可拉伸窗口，位置会保存。
关闭按钮或“收起为小按钮”会保留桌面上的“展开今日任务”入口。
点击小按钮或再次双击桌面快捷方式即可恢复卡片；右键托盘图标可完全退出。
数据仅存于本机 LocalAppData\DeskTaskAssistant\data.json，每次保存保留上一版本 .bak。
支持导出 JSON 备份和导入恢复。导入前自动保存原数据的独立副本。
程序不需要网络，不同步云端。建议定期把导出备份放到其他磁盘。

卸载
在“工作设置与备份”点击“卸载小助手”，或在 Windows 已安装的应用中卸载。
可选择保留或删除本地任务数据；已导出到其他位置的备份不会删除。
卸载会移除安装文件、自启动项、桌面及开始菜单快捷方式和卸载登记。
项目目录中的源代码、安装包不会被删除。

开发与验证
Build.ps1 可用 Windows 自带的 C# 编译器重新生成程序。
DeskTaskAssistant.exe --self-test 可运行核心调度测试，结果写到当前目录 test-results.txt。
